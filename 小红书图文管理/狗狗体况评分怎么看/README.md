# 狗狗体况评分怎么看

小红书 3:4 图文项目，主题为“狗狗体况评分怎么看？比体重更直观”。

## 文件

- `xhs-post.html`: 可编辑图文 HTML。
- `assets/xhs-images/`: 本地图文 AI 生成黑白边牧素材。
- `assets/ai-generated-border-collie/`: AI 原始生成图备份。
- `AI边牧图片素材说明.md`: AI 边牧素材说明，记录生成用途和文件对应关系。
- `xhs-native-export-server.ps1`: 原生 Edge 导出服务。
- `start-xhs-native-export-server.bat`: 双击启动导出服务。
- `exports/`: 验证截图或导出结果目录。

## 使用

1. 打开 `xhs-post.html` 预览和编辑。
2. 需要导出 PNG 时，先双击 `start-xhs-native-export-server.bat`。
3. 保持服务窗口打开，回到 HTML 点击“原生导出小红书图片”。
