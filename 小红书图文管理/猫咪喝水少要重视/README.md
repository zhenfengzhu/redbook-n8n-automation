# 猫咪喝水少要重视

## 文件
- 可编辑 HTML：`xhs-post.html`
- 最终导出图：`exports/xhs-cat-hydration-page1.png` 到 `page6.png`
- AI 素材图：`assets/xhs-images/`
- 发布文案：`发布文案.md`

## 编辑和导出
1. 用浏览器打开 `xhs-post.html`。
2. 点击右上角“编辑文字/位置”，可直接改文字、移动图片和模块，也可以删除选中元素。
3. 需要从页面导出时，先双击 `start-xhs-native-export-server.bat`，再点击页面里的“原生导出小红书图片”。
4. 本地导出服务默认保存到本文件夹的 `exports/` 目录。
