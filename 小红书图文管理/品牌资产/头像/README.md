# 小猫饭桌头像资产

## 已确认版本

- 图形：A 方向“猫耳＋饭碗”经典正脸。
- 配色：P2 珊瑚红＋蜜桃黄。
- 圆形主体外保留约 2.5% 画布安全边距，关键图形保持在平台圆形裁切区内。
- 饭碗与五官描边针对 50px 小头像略微加粗。

## 文件用途

- `xiaomao-fanzhuo-avatar-p2-master.svg`：透明四角的矢量主稿，优先保留和继续编辑。
- `xiaomao-fanzhuo-avatar-p2-cream-square.svg`：奶油白方底矢量稿。
- `exports/transparent/`：透明四角 PNG，适合平台头像和叠放使用。
- `exports/cream-square/`：奶油白方底 PNG，适合不支持透明背景的场景。
- `exports/verify/`：尺寸与圆形裁切检查图，仅用于内部确认。

PNG 分别提供 2048、1024、512、256px。平台上传优先使用 1024px 透明版；如果上传后透明区域显示异常，改用 1024px 奶油白方底版。
