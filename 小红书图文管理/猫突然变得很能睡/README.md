# 猫突然变得很能睡

## 文件

- 可编辑 HTML：`xhs-post.html`
- AI 素材图：`assets/xhs-images/`
- 原生导出服务：`start-xhs-native-export-server.bat`
- 导出图片目录：`exports/`
- 发布文案：`发布文案.md`

## 编辑和导出

1. 用浏览器打开 `xhs-post.html`。
2. 点击右上角“编辑文字/位置”，可以直接改文字、移动模块、缩放模块或删除选中元素。
3. 需要导出 1080 x 1440 图片时，先双击 `start-xhs-native-export-server.bat`，保持弹出的窗口打开。
4. 回到 HTML 页面，点击“原生导出小红书图片”。
5. 导出的图片会保存到本文件夹的 `exports/` 子目录。

## 发布前注意

不要写成“猫睡超过 16 小时就是生病”。更稳的表达是：和它自己平时相比，突然明显睡更多，并且伴随食欲、精神、互动或排泄异常时，才更需要警惕。
