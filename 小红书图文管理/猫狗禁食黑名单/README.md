# 猫狗禁食黑名单

这个文件夹用于管理这篇小红书图文。

## 文件说明

- `xhs-pet-food-blacklist.html`：主编辑文件，打开后可直接编辑文字、位置、删除模块。
- `start-xhs-native-export-server.bat`：原生截图导出启动器。
- `xhs-native-export-server.ps1`：原生导出服务脚本。
- `assets/`：图片和导出依赖。
- `exports/`：建议把最终导出的发布图放这里。

## 使用流程

1. 打开 `xhs-pet-food-blacklist.html` 编辑内容。
2. 需要导出时，双击 `start-xhs-native-export-server.bat`，保持窗口打开。
3. 回到 HTML 页面，点击 `原生导出小红书图片`。
4. 导出的图片默认保存到桌面 `XHS-Native-Exports` 文件夹。
