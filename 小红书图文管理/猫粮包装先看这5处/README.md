# 猫粮包装先看这 5 处

## 已交付

- `发布文案.md`：发布标题、6 页脚本、正文、来源与审校备注。
- `xhs-post.html`：可编辑的 6 页图文源文件。
- `assets/xhs-images/`：5 张无品牌、无文字的 AI 基础图。
- `exports/final/`：6 张 1080×1440 终版 PNG。
- `素材提示词.md`：基础图提示词与文件对应关系。

## 编辑与导出

1. 双击打开 `xhs-post.html`。
2. 点右下角“编辑文字/位置”，可直接改字、移动、缩放或删除选中元素。
3. 双击 `start-xhs-native-export-server.bat`，保持窗口打开。
4. 回到网页，点“原生导出小红书图片”。输出会进入 `exports/`。
5. 若要保存网页中的临时修改，点“下载当前 HTML”。

## 视觉规则

- 主视觉沿用方案 B：暖白纸张、浅红格子、原红色、黄色判断条。
- 错误示例固定在左侧，用红色 `✕`；正确示例固定在右侧，用低饱和绿色 `✓`。
- AI 图片不承担中文信息；关键包装文字全部由 HTML 叠加，避免乱码。
- 所有包装与标签均为无品牌示意，不对应任何实际产品。

## 发布前提醒

- 图片使用了 AI 生成素材，发布时应按平台要求使用 AI 内容标识。
- 文案用于普通成年猫食品标签科普，不替代个体营养或临床建议。
- 幼猫、老年猫、孕哺期猫、已有疾病或持续异常情况，应结合兽医意见选粮。
